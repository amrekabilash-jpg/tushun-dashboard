## 🚀 Введение

### Что такое TUSHUN Dashboard?

**TUSHUN Dashboard — это онлайн-программа, в которой вся жизнь вашего бизнеса собрана в одном месте: продажи, склад, клиенты, расходы, налоги, поставки и уведомления в Telegram.**

Откройте сайт **https://tushun-dashboard.vercel.app**, введите логин и пароль — и вы видите всё, что происходит в компании, в реальном времени.

### Для кого этот дашборд?

- 👔 **Владельцы бизнеса** — хотят видеть прибыль и проблемы каждый день, не дёргая бухгалтера
- 🧑‍💼 **Менеджеры** — управляют клиентами, счетами, поставками
- 👥 **Партнёры и инвесторы** — получают доступ к актуальным цифрам без звонков
- 📊 **Бухгалтеры** — берут готовые цифры для налоговых отчётов вместо ручных подсчётов
- 📦 **Складские работники** — видят остатки, фиксируют приход и расход

### Какие проблемы решает?

| Проблема "до" | Решение в дашборде |
|---------------|-------------------|
| «Сколько денег осталось?» — никто не знает | Module 01 → Обзор: видна выручка, расходы, прибыль за любой период |
| «Сколько товара на складе?» — нужно идти и считать | Module 02 → Остатки: всё видно мгновенно, по двум складам |
| «Кто из клиентов должен денег?» — ищем по бумагам | Module 03 → Дебиторка: список должников с суммами |
| «Сколько таможни заплатили за партию?» — копаемся в инвойсах | Module 04 → Себестоимость: разбивка по каждому товару |
| «Курс доллара?» — открываем три сайта | Module 05 → Конвертор: всё в одном клике |
| «Какой товар часто возвращают?» — нет статистики | Module 06 → Статистика: дефект-рейт по каждому товару |
| «Маркетинг превысил бюджет?» — узнаём в конце месяца | Module 07 → Анализ: алерты приходят сразу |
| «Как узнать о проблемах в выходной?» | Module 08 → Telegram-бот шлёт уведомления |

### Почему не нужно переживать о финансах

Если вы пользуетесь дашбордом **каждый день** хотя бы по 5 минут — вы:

- ✅ **Видите все деньги в реальном времени** (не нужно звонить бухгалтеру)
- ✅ **Не потеряете ни одной цифры** (всё в облаке, есть резервные копии)
- ✅ **Готовы к налоговой проверке в любой момент** (отчёты собираются автоматически)
- ✅ **Замечаете проблемы рано** (бот сразу пишет в Telegram если что-то не так)
- ✅ **Принимаете решения на основе фактов**, а не догадок

## 🎯 Раздел 1 — Зачем создан этот дашборд

### Финансовый контроль в реальном времени

В классической компании владелец узнаёт о проблемах в конце месяца — когда бухгалтер сводит цифры. К этому моменту бывает уже поздно: маркетинг потратил в три раза больше, склад пустой, а дебиторка накопилась на миллионы.

**В TUSHUN Dashboard цифры обновляются СРАЗУ** — как только сотрудник зарегистрировал продажу или оплатил счёт. Открываете дашборд утром — видите, что произошло за ночь и что планируется сегодня.

### Никаких потерь данных

Раньше бизнесы вели учёт в Excel. Вирус, сбой ноутбука, случайно удалённый файл — и **полгода работы** под угрозой.

В нашем дашборде:
- Все данные хранятся в **облаке Supabase** (профессиональный сервис)
- Каждый день автоматически делаются **резервные копии**
- Можно работать с компьютера, телефона, планшета — данные везде одинаковые
- Если у вас сгорит ноутбук — заходите с другого устройства, всё на месте

### Упрощение налоговых отчётов

Раньше для отчёта в налоговую нужно было:
1. Собрать все накладные (это 2 часа)
2. Посчитать выручку (1 час)
3. Посчитать расходы по категориям (2 часа)
4. Посчитать НДС и КПН (1 час)

**Итого: 6 часов работы каждый месяц.**

В дашборде:
1. Module 01 → Обзор → выбираете период → копируете цифры
2. Готово (5 минут)

### Автоматизация рутины

Сотрудники тратят кучу времени на:
- Перенос данных из накладной в Excel
- Расчёт маржи на калькуляторе
- Конвертацию USD в KZT по курсу НБК
- Подсчёт остатков на складе

**Дашборд делает всё это сам**:
- Маржа считается автоматически по формуле
- Курсы валют подтягиваются для всех расчётов
- Когда товар приходит — он сразу появляется на складе
- При продаже — товар автоматически списывается

### Прозрачность для всех

Партнёры, инвесторы, бухгалтеры — каждому свой логин. Каждый видит то, что ему нужно, в реальном времени. **Никаких "пришлите мне Excel-файл, я подожду" — все смотрят одни и те же актуальные цифры.**

## 📊 Раздел 2 — Как не потерять данные

### Облачное хранение Supabase PostgreSQL

Все данные — продажи, клиенты, остатки, расходы — лежат в профессиональной базе данных PostgreSQL на серверах Supabase. Это та же технология, которую используют:
- Discord (миллиарды сообщений)
- GitHub (исходный код всех проектов)
- Большинство банков

**Что это значит для вас:** ваши данные защищены от потери лучше, чем если бы они лежали на вашем ноутбуке.

### Автоматические резервные копии

Supabase каждый день автоматически создаёт копию всей вашей базы:
- 📅 Ежедневно в **00:00 UTC** (примерно 5:00 по времени Алматы)
- 💾 Хранится **7 последних копий**
- 🔄 Если что-то пойдёт не так — данные можно восстановить за 5 минут

**Пример:** случайно удалили счёт-фактуру 100 клиентов? Восстановим из вчерашней копии — потеряем максимум один день, не больше.

### Доступ с любого устройства

Дашборд — это веб-сайт. Откройте в любом браузере (Chrome, Safari, Edge) с любого устройства:

| Устройство | Работает? | Как |
|-----------|-----------|-----|
| Компьютер Windows | ✅ | Откройте Chrome → введите URL |
| MacBook | ✅ | Откройте Safari → введите URL |
| iPhone | ✅ | Safari → URL → можно "На главный экран" — будет как приложение |
| Android | ✅ | Chrome → URL → меню → "Добавить на главный экран" |
| Планшет (iPad / Android) | ✅ | Так же как телефон, удобнее из-за большого экрана |

### Синхронизация в реальном времени

Когда несколько человек работают одновременно:
- Менеджер в Алматы создаёт счёт
- Бухгалтер в Астане видит этот счёт через 2-3 секунды (после обновления страницы)
- Никаких "у меня старая версия Excel" — все видят актуальное

### Журнал всех изменений (Audit trail)

Каждое действие в дашборде записывается:
- Кто залогинился (имя пользователя + время)
- Кто создал клиента (когда и какого)
- Кто менял налоговую ставку (старое значение, новое значение)
- Кто отметил счёт оплаченным

**Зачем это нужно:**
- Если что-то пропало — можно найти кто это сделал
- Если возникнет спор «я не менял» — есть доказательства
- Бухгалтер всегда может проверить чистоту данных

> ⚠️ **Важно:** не давайте свой пароль другим — все действия будут записаны как ваши. Если нужно дать доступ — попросите завести отдельный логин.

## 💰 Раздел 3 — Финансовый учёт без переживаний

### Все доходы автоматически попадают в Module 01

Сценарий "до":
- Менеджер делает продажу
- Записывает на бумаге
- К концу дня заносит в Excel
- Бухгалтер раз в неделю переносит в 1С
- Через месяц владелец узнаёт сколько заработал

Сценарий "после":
- Менеджер регистрирует продажу в Module 03 → Счета
- В **тот же момент**:
  - Сумма попадает в выручку Module 01
  - Маржа рассчитывается автоматически
  - НДС считается по нужной ставке (12%, 16%)
  - Товар списывается со склада в Module 02
  - Запись попадает в дебиторку Module 03

**Один клик в одном месте — всё остальное само.**

### Расходы тоже автоматически

Когда вы в Module 07 регистрируете расход (например, "Аренда офиса май 950 000 ₸"):
- Сумма попадает в Module 01 → Расходы
- В Module 01 → Cashflow (движение денег) — минус с банковского счёта
- В Module 07 → Бюджет — отображается как "потрачено из лимита Аренда"
- Если лимит превышен — Module 08 шлёт алерт в Telegram

### Маржа считается сама

Формула:
```
Валовая маржа = Выручка - Себестоимость
Маржа в % = (Валовая маржа / Выручка) × 100%

Например:
  Продали фильтр за 18 000 ₸
  Себестоимость 12 600 ₸ (FOB + пошлина + НДС + фрахт)
  Маржа = 18 000 - 12 600 = 5 400 ₸ (30%)
```

Дашборд считает это автоматически для **каждой строчки счёта**, для каждого товара и за любой период.

### Налоги всегда свежие

В дашборде живут актуальные ставки:
- Таможенная пошлина
- НДС импорт (12%)
- НДС продажа (16%)
- КПН (10%)

Когда правительство меняет ставку — вы один раз обновите её в **Module 02 → Справочник товаров** или через инструмент "Налоговые ставки", и все расчёты с этого момента пойдут по новой ставке. Старые партии остаются с теми ставками, которые были тогда — это правильно с точки зрения учёта.

### Готовность к отчёту в любой момент

Хотите узнать прибыль за прошлый квартал? Открываете Module 01 → Обзор → меняете период на "90 дней". Готово.

Хотите расходы по категориям за месяц? Module 07 → Анализ → 30 дней. Готово.

Хотите сравнить план с фактом? Module 01 → План vs факт. Готово.

**Никаких ожиданий, никаких просчётов на калькуляторе.**

### 📊 Module 01 — Финансовый учёт

#### Что это
**Главный финансовый отчёт компании.** Здесь вы видите:
- Сколько заработали (выручка)
- Сколько потратили (расходы)
- Сколько прибыли (доходы минус расходы)
- Кто сколько должен (дебиторка)
- На каких банковских счетах сколько денег

#### Где найти
Левое меню → пункт **"01 Финансовый учёт"** (вверху списка модулей).

#### Вкладки

| Вкладка | Что показывает |
|---------|---------------|
| **Обзор** | Главные KPI за период: выручка / расходы / прибыль / маржа. Графики динамики |
| **Доходы** | Все продажи разбивкой по дням, клиентам, товарам |
| **Расходы** | Все расходы по категориям |
| **Cashflow** | Движение денег по банковским счетам и кассе |
| **Маржа** | Маржа по каждому товару — какие зарабатывают больше |
| **План** | Бюджет на месяц/квартал |
| **Долги** | Дебиторка — кто и сколько должен |
| **Банки** | Все банковские счета с балансами в KZT и USD |

#### Какие данные нужны
**Сами вы вводите немногое.** Module 01 — это **отчёт**, который собирает данные из других модулей:
- Продажи приходят из Module 03 (Счета)
- Расходы — из Module 07 (Расходы)
- Партии — из Module 04 (Поставки)
- Курсы валют — из Module 05

Вы только смотрите и анализируете.

#### Какие результаты получаете

**Пример вкладки "Обзор":**
```
Период: 30 дней
─────────────────────────────────
💰 Выручка:        ₸ 12,400,000
💸 Расходы:        ₸  9,800,000
📈 Прибыль:        ₸  2,600,000
📊 Маржа:          21.0%
─────────────────────────────────
📦 Продаж:         42 шт.
👥 Клиентов:       18
```

#### Формулы

```
Валовая маржа = Выручка - Себестоимость продаж
Чистая прибыль = Валовая маржа - Расходы - Налоги
Маржа % = (Валовая маржа / Выручка) × 100
ROI = (Прибыль / Инвестиции) × 100
Cashflow = Поступления - Расходы (по банкам)
```

#### Автоматизации

- 📥 **Расходы вычисляются автоматически** из кассовых транзакций (Module 07 → Module 01)
- 💱 **Курсы валют** подставляются из Module 05 для конвертации USD/EUR продаж
- 📊 **Графики обновляются** при добавлении новой продажи или расхода

#### Пример использования

> **Сценарий:** Понедельник утром, владелец хочет понять как прошёл прошлый месяц.
>
> 1. Открывает дашборд → Module 01 → Обзор
> 2. Меняет период на "30 дней"
> 3. Видит: Выручка 12.4M, Расходы 9.8M, Прибыль 2.6M, Маржа 21%
> 4. Кликает на вкладку "Маржа" — видит, что Фильтр масляный даёт 35% маржи, а Силиконовый патрубок только 12%
> 5. Решение: усилить продажи фильтров масляных, поднять цену силиконовых патрубков

### 📦 Module 02 — Товарный учёт

#### Что это
**Управление товарами и складами.** Здесь:
- Справочник всех товаров с налоговыми ставками
- Сколько каждого товара на каждом складе
- История поступлений и расходов
- Прогноз — когда нужно заказать ещё

#### Где найти
Левое меню → **"02 Товарный учёт"**.

#### Вкладки

| Вкладка | Что показывает |
|---------|---------------|
| **Обзор** | KPI по складам: всего ед., SKU, движений за неделю |
| **Справочник** | Каталог всех товаров с категориями и налогами |
| **Остатки** | Pivot-таблица товар × склад, статусы (в наличии / мало / нет) |
| **Движение** | История всех приходов/расходов/перемещений + форма для регистрации |
| **Прогноз** | Расчёт когда закончится товар при текущей скорости продаж |

#### Какие данные нужны

**Справочник товаров:**
- Название
- Категория (Фильтр масляный / Патрубок / и т.д.)
- Код ТН ВЭД (для таможни)
- Ед. измерения (шт, кг)
- Налоговые ставки (пошлина, НДС импорт, НДС продажа, КПН)

**Движения:**
- Тип: Приход / Расход / Перемещение между складами / Корректировка
- Товар + количество + склад
- Дата + документ (номер инвойса) + контрагент

#### Какие результаты получаете

**Пример вкладки "Остатки":**
```
Товар                    Алматы   Астана   Всего   Статус
────────────────────────────────────────────────────────
Фильтр масляный          200       80     280     ✓ В наличии
Фильтр воздушный         150       60     210     ✓ В наличии
Фильтр топливный          12        5      17     ⚠ Мало
Патрубок резиновый         0        0       0     ✕ Нет
```

**Пример "Прогноз":**
```
Товар                Скорость   Дней до 0   Рекомендация
────────────────────────────────────────────────────────
Фильтр топливный     5 шт/день      3        🔴 СРОЧНО заказать
Фильтр воздушный     3 шт/день     70        🟢 OK
```

#### Формулы

```
Остаток = Сумма всех приходов - Сумма всех расходов
       (агрегация по stock_movements)

Статус остатка:
  qty == 0       → "Нет в наличии" (красный)
  qty < 10       → "Мало" (жёлтый)
  qty >= 10      → "В наличии" (зелёный)

Прогноз закупок:
  Avg продаж/день = Продано за 30 дней / 30
  Дней хватит = Текущий остаток / Avg продаж
  Рекомендация = (60 дней - дней хватит) × Avg продаж
```

#### Автоматизации

### 🚚 Module 04 — Поставки и импорт

#### Что это
**Управление партиями товара.** Когда заказали у поставщика (Tushun China), сколько везут, сколько обошлось с учётом таможни и фрахта.

#### Где найти
Левое меню → **"04 Поставки и импорт"**.

#### Вкладки

| Вкладка | Что показывает |
|---------|---------------|
| **Обзор** | KPI: всего партий, в пути, общая себестоимость, средний курс |
| **Партии** | Список всех партий + форма создания новой |
| **Себестоимость** | По товарам: avg/last unit_cost, история партий |
| **Отслеживание** | Детали партии: статус, tracking, ETA, позиции, smer статуса |

#### Какие данные нужны

**Создание партии:**
- № партии (BATCH-2026-XXX)
- № инвойса от поставщика (Tushun)
- Поставщик
- Стоимость доставки (USD)
- Курс USD→KZT
- Tracking номер (waybill)
- ETA (ожидаемая дата прибытия)
- Склад назначения (Алматы / Астана)
- Позиции: товар + количество + цена/шт USD (FOB)

#### Что получаете

**Расчёт себестоимости автоматический:**

```
Партия #BATCH-2026-001:
  - Фильтр масляный × 100, FOB $8.00 = $800
  + Пошлина 12%                      = $96
  + НДС импорт 12%                   = $107.52
  + Доставка распределена            = $50
  ─────────────────────────────────────
  Итого USD:                         = $1053.52
  Курс 451.30                         × 451,30
  Себестоимость KZT                   = ₸ 475,475
  Unit cost = ₸ 4,755 за шт.
```

#### Формулы

```
FOB = Кол-во × Цена/шт USD
Customs duty = FOB × ставка_пошлины
VAT import = (FOB + Customs) × ставка_НДС
Shipping per item = Общая_доставка × (FOB_позиции / Общий_FOB)
Unit cost USD = (FOB + Customs + VAT + Shipping) / Quantity
Unit cost KZT = Unit cost USD × Курс
```

#### Статусы партии

```
draft       → черновик (только создан)
in_transit  → в пути (плывёт / летит / едет)
arrived     → прибыл (товар получен) ⚡ AUTO STOCK-IN
completed   → завершён (всё закрыто, оплачено)
cancelled   → отменён
```

#### 🔥 Автоматизации (главная фишка модуля!)

**При смене статуса на "Прибыл" (arrived):**
- ✅ Автоматически создаются движения на складе (Module 02 → Движение, тип "Приход")
- ✅ Каждая позиция партии → одна запись stock_movement
- ✅ Документ-референс = номер партии
- ✅ Идемпотентно — повторное нажатие не создаёт дубль

#### Пример

> **Сценарий:** Заказали у Tushun 1000 фильтров за $5000.
>
> 1. Module 04 → Партии → "+ Новая партия"
> 2. Заполняем: BATCH-2026-005, Tushun Co., FOB $5000, доставка $500, курс 451
> 3. Tracking: CH123456, ETA: через 3 недели
> 4. Склад: Алматы
> 5. Позиции: Фильтр масляный × 1000 @ $5
> 6. Сохраняем — статус "draft", себестоимость $5,728 (с пошлиной + НДС + доставкой)
> 7. Меняем на "В пути" когда отправили
> 8. Через 3 недели меняем на "Прибыл" → товар автоматически появляется на складе Алматы
> 9. В Module 02 → Остатки видим +1000 фильтров

#### Какие данные

- %

#### Что получаете

**Курсы:**
```
🇺🇸 USD → KZT  451.30  ↑ +0.24%  (за неделю)
🇪🇺 EUR → KZT  488.50  ↑ +1.26%
🇨🇳 CNY → KZT   62.80  ↑ +1.13%
🇷🇺 RUB → KZT    4.92  ↑ +1.44%
```

#### Формулы

```
Конвертация USD→KZT = Сумма × Курс
                    = $1000 × 451.30 = ₸451,300

Конвертация через KZT (если нет прямого курса):
  EUR → USD =
    1) EUR в KZT: 1000 × 488.50 = ₸488,500
    2) KZT в USD: 488,500 / 451.30 = $1,082.43
  Маршрут: EUR → KZT → USD

Премия процент:
  5% от чистой прибыли отдела продаж
  Если прибыль ₸2,500,000 → премия ₸125,000

Комиссия с cap:
  5% от доставки, max ₸500,000
  Доставка ₸200K → комиссия ₸10K (5%)
  Доставка ₸15M → комиссия ₸500K (cap сработал)
```

#### Автоматизации

- 💱 Курсы используются в Module 04 для расчёта себестоимости в KZT
- 💱 Курсы используются в Module 01 для конвертации USD-выручки
- 🔄 Цепочка через KZT — если нет прямого курса EUR→USD, автоматически рассчитывается через KZT

```
Trend = (Forecast этого месяца - Прошлый месяц) / Прошлый × 100
```

## 🚀 Раздел 5 — Автоматизации (что работает само)

Дашборд экономит ваше время за счёт того, что многое делается **без вашего участия**:

### 1. Партия прибыла → товар на складе (Module 04 → Module 02)

Когда вы меняете статус партии импорта на **"Прибыл"**:
- ✅ Каждая позиция партии превращается в запись на складе
- ✅ Документ-референс = номер партии (BATCH-2026-XXX)
- ✅ Дата прибытия = дата движения
- ✅ Защита от дубля (повторное нажатие не создаст дубль)

**Раньше:** менеджер вручную записывал поступления в Excel, потом операционист переносил в 1С.
**Теперь:** один клик — товар на складе.

### 2. Превышение бюджета → Telegram-алерт (Module 07 → Module 08)

Когда расход в категории превышает лимит:
- ✅ Категория помечается красным в Module 07
- ✅ Подписчики Telegram получают сообщение типа:
  ```
  🔴 Критичное превышение бюджета
  Категория: Зарплата
  Использовано: 166%
  Превышение: ₸3,320,000
  ```

**Раньше:** узнавали в конце месяца, когда уже не вернуть.
**Теперь:** узнаёте через 5 секунд после того как расход проведён.

### 3. Курс валюты → пересчёт всех зависимых сумм (Module 05 → Module 04, 01)

Когда вы добавляете новый курс USD/KZT:
- ✅ Новые партии импорта считаются по новому курсу
- ✅ Module 01 показывает банковские счета в USD с актуальным эквивалентом в KZT
- ✅ Конвертор показывает свежие значения

> ⚠️ **Замечание:** старые партии **не пересчитываются** — это правильно с точки зрения учёта. Если вы зафиксировали себестоимость по курсу 450, она такой и останется в истории.

### 4. Кассовая транзакция → автоматически в финотчёт (Module 07 → Module 01)

Когда вы регистрируете расход через Module 07:
- ✅ Сумма уменьшает баланс банковского счёта в Module 01 → Cashflow
- ✅ Сумма попадает в Module 01 → Расходы за период
- ✅ Категория используется для группировки в P&L

### 5. Auto-номер документа

- ✅ **Счёт-фактура:** СФ-2026-XXX (автоинкремент)
- ✅ **Партия импорта:** BATCH-2026-XXX
- ✅ **Рекламация:** РК-2026-XXX

Не нужно держать в голове следующий номер — система сама подставляет.

### 6. Расчёт налогов в продажах

При создании счёта-фактуры:
- ✅ НДС вход = себестоимость × 12%
- ✅ НДС выход = выручка × 16%
- ✅ НДС к уплате = выход - вход
- ✅ КПН = (валовая маржа - НДС к уплате) × 10%
- ✅ Чистая прибыль = валовая маржа - НДС - КПН

**Всё считается автоматически. Вы вводите только цену и количество.**

### 7. Aging-анализ дебиторки (Module 03)

Каждый день автоматически пересчитываются корзины:
- current → счёт ещё не просрочен
- 0-30 → просрочка до месяца
- 31-60, 61-90, 90+ → дальше

Не нужно ручками сверять каждый счёт с календарём.

### 8. Прогноз закупок (Module 02)

На основе истории продаж за 30 дней автоматически рассчитывается:
- Скорость продаж (шт/день)
- Дней до 0 (сколько хватит при текущем темпе)
- Рекомендация по закупке (на следующие 60 дней)

Не нужно вести Excel-таблицу с динамикой — всё в дашборде.

## 📈 Раздел 7 — Как готовить налоговые отчёты

### Где брать выручку за период

**Module 01 → Обзор**
- Выберите период: 30 / 90 / 365 дней
- Поле "Выручка" — это ваша валовая выручка
- Поле "НДС к уплате" — это сумма НДС для отчёта

### Где брать расходы по категориям

**Module 07 → Анализ → выберите период**
- Видите PieChart распределения по категориям
- Внизу таблица "Детально по товарам" — точные суммы
- Каждая категория с количеством операций

> 📋 **Что давать бухгалтеру:** Module 07 → Анализ → нажмите Export (если включён) или скриншот.

### Где брать себестоимость для COGS (Cost of Goods Sold)

**Module 04 → Себестоимость**
- Кликните на товар → разворачивается история партий
- Видите для каждой партии: FOB, пошлина, НДС импорт, итого USD/KZT
- Avg unit cost — средняя себестоимость единицы

> 📋 **Что давать бухгалтеру:** скриншот разворачивающегося блока для каждого активного товара.

### Где брать движение денег (Cash Flow)

**Module 01 → Cashflow** (или вкладка Банки)
- Все банковские счета с балансами
- Поступления / выбытия за период
- Разница = чистый денежный поток

### Налоги в одном месте

В Module 01 → Обзор показываются для выбранного периода:
- НДС к уплате (выход − вход)
- КПН (10% от прибыли после НДС)
- Чистая прибыль (после всех налогов)

### Время на отчёт: 5 минут вместо часа

**Сценарий "сделать налоговую за месяц":**

1. Module 01 → Обзор → 30 дней → копируете: Выручка, Себестоимость, Маржа, НДС, КПН → 1 минута
2. Module 07 → Анализ → 30 дней → копируете расходы по категориям → 1 минута
3. Module 04 → Себестоимость → проверяете партии активные в этом периоде → 1 минута
4. Module 03 → Счета → фильтр "Оплачены" за период → видна реальная выручка по cash basis → 1 минута
5. Скриншоты + цифры → отправляете бухгалтеру → 1 минута

**Итого: 5 минут.** Раньше это занимало полдня.

### Совет для бухгалтера

Дайте бухгалтеру свой логин (или создайте отдельный — это бесплатно). Он сам зайдёт и заберёт что нужно — без ваших звонков и пересылки файлов.

## 🔐 Раздел 8 — Безопасность и защита данных

### Где хранятся ваши данные

**Supabase (PostgreSQL)** — профессиональная база данных в дата-центре AWS Frankfurt (Германия). Та же платформа используется крупнейшими компаниями мира.

**Что это даёт:**
- 🛡 Защита от потери (data redundancy — дубли на разных серверах)
- 🌍 Соответствие GDPR (европейское регулирование защиты данных)
- ⚡ Скорость доступа отовсюду (CDN)

### Резервные копии

Supabase делает автоматические backup каждый день:
- 📅 **Где:** автономно от основной БД
- 🕐 **Когда:** 00:00 UTC (~5:00 Алматы)
- 💾 **Сколько хранится:** 7 последних копий

**Сценарий восстановления:**
- Кто-то случайно удалил всех клиентов
- Заходим в Supabase Dashboard → Backups
- Выбираем backup от вчера → Restore
- За 5 минут БД восстановлена в состоянии вчерашнего вечера

### Защита от взлома

#### Аутентификация

- 🔑 У каждого пользователя свой пароль
- 🔒 Пароли хранятся **захэшированные** (bcrypt) — даже сотрудники Supabase их не видят
- 🎫 После логина выдаётся JWT-токен на 24 часа
- ⏰ Через 24 часа нужно залогиниться заново

#### Защита базы данных

- 🚫 **Anon-доступ заблокирован** (Row Level Security включена на всех 24 таблицах) — никто не может прочитать БД минуя backend
- 🌐 **Backend на Railway** — единственный кто может читать/писать
- 🔐 **CORS-защита** — только запросы с `tushun-dashboard.vercel.app` принимаются

### Журнал изменений

Каждое действие записывается:
- Изменение налоговой ставки → Module 02 → история ставок (когда, кто, на сколько)
- Регистрация платежа → видно в Module 03 → Детали счёта (created_by, created_at)
- Создание клиента → видно когда и кем

### Доступ для команды

Каждому сотруднику → отдельный логин. Если человек уволился — пароль меняется (или аккаунт удаляется), и доступ прекращается.

**Плохая практика:** один общий пароль на всех.
**Хорошая практика:** свой логин у каждого.

### Что делать если потеряли пароль

Сейчас восстановление через техподдержку (свяжитесь с админом). В будущей версии будет «Забыли пароль?» — сброс через email.

## ❓ Раздел 10 — Часто задаваемые вопросы (FAQ)

### Q1: Потеряю ли я данные?

**A:** Нет. Все данные хранятся в облаке Supabase (профессиональная PostgreSQL база). Каждый день автоматически делается резервная копия. Даже если у вас сгорит компьютер — всё на месте.

### Q2: Могу ли я работать с телефона?

**A:** Да. Дашборд — это веб-сайт, открывается в любом браузере с любого устройства. Адрес: https://tushun-dashboard.vercel.app. Удобнее на планшете или ноутбуке (большие таблицы лучше видно), но и на телефоне работает.

### Q3: Сколько пользователей могут работать одновременно?

**A:** Сколько угодно. Каждый со своим логином. Все видят актуальные данные в реальном времени. Конфликтов нет.

### Q4: Как считается маржа?

**A:**
```
Валовая маржа = Выручка - Себестоимость
Маржа в % = (Валовая маржа / Выручка) × 100
```
Считается автоматически в каждой строке счёта-фактуры (Module 03 → Детали счёта).

### Q5: Как считается себестоимость импортного товара?

**A:**
```
Unit cost USD = (FOB + Пошлина + НДС импорт + Доставка) / Количество
Unit cost KZT = Unit cost USD × Курс
```
Считается автоматически в Module 04 при создании партии. Доставка распределяется пропорционально FOB между всеми товарами партии.

### Q6: Что делать если нашёл ошибку в данных?

**A:**
- Если расход не той категории → Module 07 → Расходы → клик на строку → меняете категорию
- Если цена в счёте неправильная → Module 03 → Счета → меняете (пока статус draft) или делаете correction-платёж (если уже выпущен)
- Если ошиблись в количестве товара на складе → Module 02 → Движение → создать "Корректировка" с правильным значением

### Q7: Кто может видеть мои данные?

**A:** Только пользователи, у которых есть логин и пароль от вашего дашборда. Снаружи через Supabase API доступ заблокирован (RLS). Внутри компании — только те, кому вы дали доступ.

### Q8: Что если интернет пропадёт?

**A:** Дашборд требует интернет (это не оффлайн-программа). Если связь пропала — вы не сможете внести изменения, но они **не потеряются**. Вернётся интернет — продолжите. Также можно работать с мобильного интернета (3G/4G).

### Q9: Можно ли экспортировать данные в Excel?

**A:** В текущей версии экспорт не включён в UI, но можно сделать:
- Скриншот таблицы
- Через Supabase Dashboard → Table Editor → Export to CSV (для админов)
- В будущей версии добавим кнопки Export рядом с каждой таблицей

### Q10: Как добавить нового пользователя?

**A:**
- Сейчас через техподдержку или администратора (он создаст логин в Supabase Auth + наша таблица users)
- В будущей версии — через UI Module 08 (или отдельный Settings)

### Q11: Что делать если бот в Telegram не отвечает?

**A:**
- Если в Module 08 → Banner написано "⚠ Demo-режим (без TELEGRAM_BOT_TOKEN)" — бот в режиме симуляции, реальные сообщения не отправляются. Чтобы включить — нужен токен от @BotFather, его прописывает админ в Railway.
- Если bot должен работать, но молчит — проверьте подписку (Module 08 → Подписчики → найдите себя → проверьте отметки на типах уведомлений)

### Q12: Как изменить пароль?

**A:** Сейчас через админа. В будущей версии — через раздел Profile / Settings.

### Q13: Сколько стоит дашборд?

**A:** Сейчас работает на бесплатных тарифах:
- Vercel Free (frontend) — до 100GB трафика/мес
- Railway Trial (backend) — $5 кредита/мес
- Supabase Free (БД) — 500MB данных, безлимит запросов

Когда вырастете — переходите на платные планы (~$40/мес total за всё).

### Q14: Что если сервер сломается?

**A:**
- Vercel и Railway имеют SLA 99.9% (даунтайм максимум 1 час в год)
- Supabase делает hot-failover (если один сервер упал, другой подхватывает)
- Реально приложение должно работать практически без перерывов

### Q15: Можно ли использовать в мобильном приложении?

**A:** В планах. Сейчас — только веб. Можно "добавить на главный экран" (PWA-режим) — иконка появится как у обычного приложения.

## 🎯 Заключение

### Почему компания может спать спокойно

**Финансы под контролем**
Всё, что происходит с деньгами вашей компании — учтено. Каждая продажа, каждый расход, каждый платёж — в дашборде. Открываете утром → видите состояние бизнеса.

**Данные не потеряются**
Они в облаке профессионального уровня (Supabase) с ежедневными резервными копиями. Даже катастрофа на офисном сервере не повлияет на ваши данные.

**Налоги подготовлены**
Не нужно паниковать в конце квартала. Все цифры готовы — копируете и отдаёте бухгалтеру за 5 минут.

**Сотрудники работают эффективнее**
Меньше Excel, меньше ручных подсчётов, меньше ошибок. Больше времени на анализ и развитие бизнеса.

**Бизнес развивается**
Видите слабые места (низкая маржа на товаре X) и сильные стороны (категория Y растёт +30% в месяц). Принимаете решения на основе фактов, а не догадок.
